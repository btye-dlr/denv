# Ways of working

## Start a session

Read the cognition pack in the order documented by `AGENTS.md`. Restate the
active goal, constraints, and evidence needed for completion before changing
the workspace.

## During a session

- Keep one active goal.
- Write durable “why” as an ADR, not only in chat.
- Update project memory only with stable, reusable facts.
- Re-read constraints after context compression or a long detour.
- Stop and reconcile conflicts between chat, code, and recorded decisions.

## Close a session

Update `sessions/CURRENT.md` with goal, constraints, completed work, next
actions, risks, and durable links. Archive it when work changes to a new goal.
